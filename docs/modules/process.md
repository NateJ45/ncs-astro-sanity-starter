# Process page

The process page is part of the core starter. No enable steps are needed.

- Route `/process` is always available once the starter is deployed.
- Schemas live in `studio/schemaTypes/processPage.ts` and `studio/schemaTypes/processStep.ts`.
- Default section visibility is controlled in `src/data/defaultSections.ts`.
- For architecture details see [docs/agent/page-architecture.md](../agent/page-architecture.md).
