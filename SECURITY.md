# Security Policy

## Supported versions

Only the `main` branch is supported. Fixes land on `main`; there are no maintained release branches.

## Reporting a vulnerability

Please report security issues privately by email to **nathan@nixoncreativestudio.com**. Do not open a public issue or pull request for a vulnerability.

Include a description of the issue, the steps or proof of concept to reproduce it, and the commit or deploy you saw it on. You will get an acknowledgement, and the fix and any disclosure will be coordinated with you.
